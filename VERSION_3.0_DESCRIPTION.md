# Описание версии 3.0 — Bitcoin Analyzer PRO

Эта версия содержит крупные обновления интерфейса, новые индикаторы профессионального уровня и оптимизацию производительности.

---

## 1. Добавленные индикаторы (4 новые метрики)
* **Taker Volume & Delta**: Отображение объема покупок/продаж по рыночным ордерам (Taker Buy/Sell) и чистой дельты (Delta) в реальном времени для оценки агрессивных участников рынка.
* **Funding Rate (Ставка финансирования)**: Автоматический запрос текущей ставки финансирования (Binance Futures BTCUSDT) для отслеживания перекоса лонгов/шортов на фьючерсном рынке.
* **Live Liquidations (Ликвидации)**: Панель отслеживания крупных ликвидаций лонгов и шортов в реальном времени.
* **Long/Short Ratio**: Соотношение открытых позиций лонг/шорт на рынке.

## 2. Визуализация пулов ликвидности (Liquidation Pools)
* Алгоритм определяет ключевые экстремумы (Swing High/Low) по историческим свечам.
* Линии пулов ликвидности отображаются на графике в виде кластеров стоп-лоссов/ликвидаций.
* При пересечении ценой (Breakout) линии автоматически завершаются, имитируя сбор ликвидности профессиональными маркет-мейкерами.

## 3. Оптимизация интерфейса и логики
* **Миграция Squeeze Screener**: Скринер сквизов переведен на полностью ручной запуск по клику (вместо автоматического ежесекундного запроса), что снижает нагрузку на API и предотвращает блокировку IP-адреса.
* **Синхронизация мигания сигналов**:
  * Мигание (блинк) ограничено только высокоприоритетными сигналами **LONG** (когда StochRSI K <= 15).
  * Убрано раздражающее мигание с нейтральных зон, вертикальной шкалы ADX и слабых сигналов.
